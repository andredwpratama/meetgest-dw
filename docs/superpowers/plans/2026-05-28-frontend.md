# Meeting Transcript Processor — Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy the React frontend that consumes the deployed backend: paste/upload a transcript, process it, inline-edit results with debounced auto-save, browse history, and export to Markdown or PDF.

**Architecture:** Vite + React + Tailwind + shadcn/ui SPA with `react-router-dom`. All HTTP goes through a single typed `api` client. Inline editors PATCH individual rows on debounce; export builds from the current edited state.

**Tech Stack:** Vite, React 18, TypeScript, Tailwind, shadcn/ui, react-router-dom, zod (only if needed client-side), jspdf, vitest + jsdom, `@testing-library/react`.

**Source of truth for product decisions:** `CLAUDE.md`.

**Dependencies:** the backend plan (`2026-05-28-backend.md`) must be complete. Specifically, `docs/submission/BACKEND_URL.txt` must contain the deployed Workers URL before Task 8.

```ts
import type { ActionItem, KeyDecision, Meeting, MeetingPreview, ApiError } from "./types";

const BASE = import.meta.env.VITE_API_URL as string;

async function request<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await fetch(`${BASE}${path}`, {
    ...init,
    headers: { "Content-Type": "application/json", ...(init?.headers ?? {}) },
  });
  if (!res.ok) {
    let body: ApiError = { error: "network_error", message: res.statusText };
    try { body = (await res.json()) as ApiError; } catch { /* ignore */ }
    throw Object.assign(new Error(body.error), { apiError: body, status: res.status });
  }
  if (res.status === 204) return undefined as T;
  return (await res.json()) as T;
}

export const api = {
  process: (title: string, transcript: string) =>
    request<Meeting>("/api/process", { method: "POST", body: JSON.stringify({ title, transcript }) }),
  listMeetings: () => request<MeetingPreview[]>("/api/meetings"),
  getMeeting: (id: string) => request<Meeting>(`/api/meetings/${id}`),
  patchMeeting: (id: string, patch: { title?: string; summary?: string }) =>
    request<Meeting>(`/api/meetings/${id}`, { method: "PATCH", body: JSON.stringify(patch) }),

  addActionItem: (meetingId: string, body: { task: string; owner?: string | null; deadline?: string | null }) =>
    request<ActionItem>(`/api/meetings/${meetingId}/action-items`, { method: "POST", body: JSON.stringify(body) }),
  patchActionItem: (id: string, patch: Partial<{ task: string; owner: string | null; deadline: string | null; position: number }>) =>
    request<ActionItem>(`/api/action-items/${id}`, { method: "PATCH", body: JSON.stringify(patch) }),
  deleteActionItem: (id: string) => request<void>(`/api/action-items/${id}`, { method: "DELETE" }),

  addKeyDecision: (meetingId: string, text: string) =>
    request<KeyDecision>(`/api/meetings/${meetingId}/key-decisions`, { method: "POST", body: JSON.stringify({ text }) }),
  patchKeyDecision: (id: string, patch: Partial<{ text: string; position: number }>) =>
    request<KeyDecision>(`/api/key-decisions/${id}`, { method: "PATCH", body: JSON.stringify(patch) }),
  deleteKeyDecision: (id: string) => request<void>(`/api/key-decisions/${id}`, { method: "DELETE" }),
};
```

```tsx
import { useRef, useState, DragEvent } from "react";
import { Textarea } from "@/components/ui/textarea";
import { Input } from "@/components/ui/input";
import { Button } from "@/components/ui/button";
import { Label } from "@/components/ui/label";

type Props = {
  title: string; setTitle: (v: string) => void;
  transcript: string; setTranscript: (v: string) => void;
  onProcess: () => void;
  processing: boolean;
  error: string | null;
};

export function TranscriptInput(p: Props) {
  const [drag, setDrag] = useState(false);
  const fileRef = useRef<HTMLInputElement>(null);

  async function readFile(file: File) {
    if (!file.name.endsWith(".txt") && file.type !== "text/plain") {
      alert("Please upload a .txt file.");
      return;
    }
    p.setTranscript(await file.text());
  }
  function onDrop(e: DragEvent<HTMLDivElement>) {
    e.preventDefault(); setDrag(false);
    const f = e.dataTransfer.files?.[0];
    if (f) readFile(f);
  }

  const canProcess = p.title.trim().length > 0 && p.transcript.trim().length >= 200 && !p.processing;

  return (
    <div className="space-y-4 max-w-3xl">
      <div className="space-y-2">
        <Label htmlFor="title">Meeting title</Label>
        <Input id="title" value={p.title} onChange={(e) => p.setTitle(e.target.value)} placeholder="e.g. Q3 client review" />
      </div>

      <div className="space-y-2">
        <Label>Transcript</Label>
        <div
          onDragOver={(e) => { e.preventDefault(); setDrag(true); }}
          onDragLeave={() => setDrag(false)}
          onDrop={onDrop}
          className={`rounded-md border-2 border-dashed p-2 transition ${drag ? "border-slate-900 bg-slate-50" : "border-slate-300"}`}
        >
          <Textarea
            value={p.transcript}
            onChange={(e) => p.setTranscript(e.target.value)}
            rows={14}
            placeholder="Paste the raw transcript here, or drop a .txt file onto this box."
            className="border-none focus-visible:ring-0"
          />
          <div className="flex items-center justify-between px-1 pt-2 text-sm text-slate-500">
            <button type="button" className="underline" onClick={() => fileRef.current?.click()}>upload .txt</button>
            <span>{p.transcript.length.toLocaleString()} chars</span>
          </div>
          <input ref={fileRef} type="file" accept=".txt,text/plain" hidden onChange={(e) => {
            const f = e.target.files?.[0]; if (f) readFile(f);
          }} />
        </div>
      </div>

      {p.error && <div className="rounded-md bg-red-50 border border-red-200 text-red-800 px-3 py-2 text-sm">{p.error}</div>}

      <Button onClick={p.onProcess} disabled={!canProcess}>
        {p.processing ? "Processing…" : "Process transcript"}
      </Button>
    </div>
  );
}
```

```tsx
import { useState } from "react";
import { TranscriptInput } from "@/components/TranscriptInput";
import { api } from "@/lib/api";
import type { Meeting } from "@/lib/types";

export function ProcessorPage() {
  const [title, setTitle] = useState("");
  const [transcript, setTranscript] = useState("");
  const [meeting, setMeeting] = useState<Meeting | null>(null);
  const [processing, setProcessing] = useState(false);

    setProcessing(true); setError(null);
    try {
      const m = await api.process(title, transcript);
      setMeeting(m);
    } catch (e: unknown) {
      const msg = (e as { apiError?: { error: string } })?.apiError?.error ?? "unknown_error";
      const human: Record<string, string> = {
        transcript_too_short: "The transcript is too short — please paste at least 200 characters.",
        transcript_too_long: "The transcript is too long (max 100,000 characters). Trim and retry.",
        llm_invalid_output: "The model returned invalid output even after a retry. Try again or shorten the transcript.",
      };
      setError(human[msg] ?? "Something went wrong. Please try again.");
    } finally {
      setProcessing(false);
    }
  }

  if (meeting) {
    return (
      <div className="space-y-4 max-w-3xl">
        <button className="text-sm text-slate-600 underline" onClick={() => setMeeting(null)}>← Process another</button>
        <pre className="bg-slate-50 border rounded p-3 text-xs overflow-auto">{JSON.stringify(meeting, null, 2)}</pre>
      </div>
    );
  }

  return (
    <TranscriptInput
      title={title} setTitle={setTitle}
      transcript={transcript} setTranscript={setTranscript}

  );
}
```

```ts
import { useEffect } from "react";

export function useDebouncedEffect(effect: () => void | Promise<void>, deps: unknown[], delayMs: number) {
  useEffect(() => {
    const t = setTimeout(effect, delayMs);
    return () => clearTimeout(t);
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, deps);
}
```

- [ ] **Step 2: Create `frontend/src/components/ActionItemEditor.tsx`**

```tsx
import { useEffect, useState } from "react";
import { Input } from "@/components/ui/input";
import { Button } from "@/components/ui/button";
import { useDebouncedEffect } from "@/hooks/useDebouncedEffect";
import { api } from "@/lib/api";
import type { ActionItem } from "@/lib/types";

export function ActionItemEditor({
  item, onChange, onDelete,
}: { item: ActionItem; onChange: (a: ActionItem) => void; onDelete: () => void }) {
  const [task, setTask] = useState(item.task);
  const [owner, setOwner] = useState(item.owner ?? "");
  const [deadline, setDeadline] = useState(item.deadline ?? "");

  useEffect(() => { setTask(item.task); setOwner(item.owner ?? ""); setDeadline(item.deadline ?? ""); }, [item.id]);

  useDebouncedEffect(async () => {
    const patch = {
      task,
      owner: owner.trim() === "" ? null : owner,
      deadline: deadline.trim() === "" ? null : deadline,
    };
    if (patch.task === item.task && patch.owner === item.owner && patch.deadline === item.deadline) return;
    try {
      const updated = await api.patchActionItem(item.id, patch);
      onChange(updated);
    } catch { /* surface elsewhere later */ }
  }, [task, owner, deadline], 500);

  return (
    <div className="grid grid-cols-12 gap-2 items-start">
      <Input className="col-span-6" value={task} onChange={(e) => setTask(e.target.value)} placeholder="Task" />
      <Input className="col-span-3" value={owner} onChange={(e) => setOwner(e.target.value)} placeholder="Owner (optional)" />
      <Input className="col-span-2" value={deadline} onChange={(e) => setDeadline(e.target.value)} placeholder="Deadline (optional)" />
      <Button variant="ghost" className="col-span-1" onClick={onDelete} aria-label="Delete">✕</Button>
    </div>
  );
}
```

```tsx
import { useEffect, useState } from "react";
import { Textarea } from "@/components/ui/textarea";
import { Input } from "@/components/ui/input";
import { Button } from "@/components/ui/button";
import { Card } from "@/components/ui/card";
import { useDebouncedEffect } from "@/hooks/useDebouncedEffect";
import { ActionItemEditor } from "./ActionItemEditor";
import { KeyDecisionEditor } from "./KeyDecisionEditor";
import { ExportMenu } from "./ExportMenu";
import { api } from "@/lib/api";
import type { Meeting } from "@/lib/types";

export function ResultsPanel({
  meeting, onChange,
}: { meeting: Meeting; onChange: (m: Meeting) => void }) {
  const [title, setTitle] = useState(meeting.title);
  const [summary, setSummary] = useState(meeting.summary);

  useEffect(() => { setTitle(meeting.title); setSummary(meeting.summary); }, [meeting.id]);

  useDebouncedEffect(async () => {
    const patch: { title?: string; summary?: string } = {};
    if (title !== meeting.title) patch.title = title;
    if (summary !== meeting.summary) patch.summary = summary;
    if (!patch.title && !patch.summary) return;
    try {
      const updated = await api.patchMeeting(meeting.id, patch);
      onChange(updated);
    } catch { /* ignore */ }
  }, [title, summary], 500);

  async function addActionItem() {
    const created = await api.addActionItem(meeting.id, { task: "" });
    onChange({ ...meeting, action_items: [...meeting.action_items, created] });
  }
  async function deleteAction(id: string) {
    await api.deleteActionItem(id);
    onChange({ ...meeting, action_items: meeting.action_items.filter((a) => a.id !== id) });
  }
  async function addDecision() {
    const created = await api.addKeyDecision(meeting.id, "");
    onChange({ ...meeting, key_decisions: [...meeting.key_decisions, created] });
  }
  async function deleteDecision(id: string) {
    await api.deleteKeyDecision(id);
    onChange({ ...meeting, key_decisions: meeting.key_decisions.filter((d) => d.id !== id) });
  }

  return (
    <div className="space-y-6 max-w-4xl">
      <div className="flex justify-between items-center">
        <Input value={title} onChange={(e) => setTitle(e.target.value)} className="text-2xl font-semibold border-none px-0 focus-visible:ring-0" />
        <ExportMenu meeting={{ ...meeting, title, summary }} />
      </div>

      <Card className="p-4 space-y-2">
        <div className="text-xs uppercase tracking-wide text-slate-500">Summary</div>
        <Textarea rows={5} value={summary} onChange={(e) => setSummary(e.target.value)} />
      </Card>

      <Card className="p-4 space-y-3">
        <div className="flex justify-between items-center">
          <div className="text-xs uppercase tracking-wide text-slate-500">Action items</div>
          <Button variant="outline" size="sm" onClick={addActionItem}>+ Add</Button>
        </div>
        {meeting.action_items.length === 0 && <div className="text-sm text-slate-500">No action items.</div>}
        <div className="space-y-2">
          {meeting.action_items.map((a) => (
            <ActionItemEditor
              key={a.id}
              item={a}
              onChange={(updated) =>
                onChange({ ...meeting, action_items: meeting.action_items.map((x) => (x.id === updated.id ? updated : x)) })
              }
              onDelete={() => deleteAction(a.id)}
            />
          ))}
        </div>
      </Card>

      <Card className="p-4 space-y-3">
        <div className="flex justify-between items-center">
          <div className="text-xs uppercase tracking-wide text-slate-500">Key decisions</div>
          <Button variant="outline" size="sm" onClick={addDecision}>+ Add</Button>
        </div>
        {meeting.key_decisions.length === 0 && <div className="text-sm text-slate-500">No key decisions.</div>}
        <div className="space-y-2">
          {meeting.key_decisions.map((d) => (
            <KeyDecisionEditor
              key={d.id}
              item={d}
              onChange={(updated) =>
                onChange({ ...meeting, key_decisions: meeting.key_decisions.map((x) => (x.id === updated.id ? updated : x)) })

            />
          ))}

      </Card>
    </div>
  );
}
```

```ts
import { jsPDF } from "jspdf";
import type { Meeting } from "./types";

export function toMarkdown(m: Meeting): string {
  const lines: string[] = [];
  lines.push(`# ${m.title}`);
  lines.push("");
  lines.push(`*Processed on ${new Date(m.created_at).toLocaleString()}*`);
  lines.push("");
  lines.push("## Summary");
  lines.push("");
  lines.push(m.summary || "_No summary._");
  lines.push("");
  lines.push("## Action Items");
  lines.push("");
  if (m.action_items.length === 0) lines.push("_No action items._");
  for (const a of m.action_items) {
    const owner = a.owner ? ` — **${a.owner}**` : "";
    const deadline = a.deadline ? ` _(${a.deadline})_` : "";
    lines.push(`- ${a.task}${owner}${deadline}`);
  }
  lines.push("");
  lines.push("## Key Decisions");
  lines.push("");
  if (m.key_decisions.length === 0) lines.push("_No key decisions._");
  for (const d of m.key_decisions) lines.push(`- ${d.text}`);
  lines.push("");
  return lines.join("\n");
}

function slug(s: string): string {
  return s.toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/^-|-$/g, "").slice(0, 60) || "meeting";
}

export function downloadMarkdown(m: Meeting) {
  const blob = new Blob([toMarkdown(m)], { type: "text/markdown;charset=utf-8" });
  const url = URL.createObjectURL(blob);
  const a = document.createElement("a");
  a.href = url; a.download = `${slug(m.title)}.md`;
  document.body.appendChild(a); a.click(); a.remove();
  URL.revokeObjectURL(url);
}

export function downloadPdf(m: Meeting) {
  const doc = new jsPDF({ unit: "pt", format: "letter" });
  const margin = 48;
  const pageWidth = doc.internal.pageSize.getWidth();
  const wrapWidth = pageWidth - margin * 2;
  let y = margin;

  function line(text: string, opts: { size?: number; bold?: boolean; gap?: number } = {}) {
    const size = opts.size ?? 11;
    doc.setFont("helvetica", opts.bold ? "bold" : "normal");
    doc.setFontSize(size);
    const wrapped = doc.splitTextToSize(text, wrapWidth);
    for (const w of wrapped) {
      if (y > doc.internal.pageSize.getHeight() - margin) { doc.addPage(); y = margin; }
      doc.text(w, margin, y);
      y += size * 1.3;
    }
    y += opts.gap ?? 4;
  }

  line(m.title, { size: 18, bold: true, gap: 8 });
  line(`Processed on ${new Date(m.created_at).toLocaleString()}`, { size: 9 });
  y += 6;
  line("Summary", { size: 13, bold: true, gap: 6 });
  line(m.summary || "No summary.");
  y += 6;
  line("Action Items", { size: 13, bold: true, gap: 6 });
  if (m.action_items.length === 0) line("No action items.");
  for (const a of m.action_items) {
    const owner = a.owner ? ` — ${a.owner}` : "";
    const deadline = a.deadline ? ` (${a.deadline})` : "";
    line(`• ${a.task}${owner}${deadline}`);
  }
  y += 6;
  line("Key Decisions", { size: 13, bold: true, gap: 6 });
  if (m.key_decisions.length === 0) line("No key decisions.");
  for (const d of m.key_decisions) line(`• ${d.text}`);

  doc.save(`${slug(m.title)}.pdf`);
}
```

- [ ] **Step 2: Rewrite `frontend/src/pages/ProcessorPage.tsx` to support deep-link by `?id=`**

```tsx
import { useEffect, useState } from "react";
import { useSearchParams } from "react-router-dom";
import { TranscriptInput } from "@/components/TranscriptInput";
import { ResultsPanel } from "@/components/ResultsPanel";
import { api } from "@/lib/api";
import type { Meeting } from "@/lib/types";

export function ProcessorPage() {
  const [params, setParams] = useSearchParams();
  const [title, setTitle] = useState("");
  const [transcript, setTranscript] = useState("");
  const [meeting, setMeeting] = useState<Meeting | null>(null);
  const [processing, setProcessing] = useState(false);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    const id = params.get("id");
    if (!id) return;
    api.getMeeting(id).then(setMeeting).catch(() => setError("Could not load that meeting."));
  }, [params]);

  async function process() {
    setProcessing(true); setError(null);
    try {
      const m = await api.process(title, transcript);
      setMeeting(m);
    } catch (e: unknown) {
      const msg = (e as { apiError?: { error: string } })?.apiError?.error ?? "unknown_error";
      const human: Record<string, string> = {
        transcript_too_short: "The transcript is too short — please paste at least 200 characters.",
        transcript_too_long: "The transcript is too long (max 100,000 characters). Trim and retry.",
        llm_invalid_output: "The model returned invalid output even after a retry. Try again or shorten the transcript.",
      };
      setError(human[msg] ?? "Something went wrong. Please try again.");
    } finally {
      setProcessing(false);
    }
  }

  function processAnother() {
    setMeeting(null);
    if (params.get("id")) {
      params.delete("id");
      setParams(params, { replace: true });
    }
  }

  if (meeting) {
    return (
      <div>
        <button className="mb-4 text-sm text-slate-600 underline" onClick={processAnother}>← Process another</button>
        <ResultsPanel meeting={meeting} onChange={setMeeting} />
      </div>
    );
  }

  return (
    <TranscriptInput
      title={title} setTitle={setTitle}
      transcript={transcript} setTranscript={setTranscript}
      onProcess={process} processing={processing} error={error}
    />
  );
}
```

```markdown
## System Prompt

## Stack & Why

- **Backend:** Hono on Cloudflare Workers — TS-native, fast cold starts, free tier, native D1 binding.
- **DB:** Cloudflare D1 (SQLite) — single binding, no connection pool, three normalized tables (`meetings`, `action_items`, `key_decisions`) so inline edits are single-row updates.
- **Frontend:** Vite + React + Tailwind + shadcn/ui — fast dev loop, accessible primitives, no heavy UI library.
- **LLM:** OpenRouter → `openai/gpt-oss-120b:free` — zero billing for public deploy. Reliability handled at the system level: zod-validated JSON, retry once on malformed output, human review.
- **Observability:** Langfuse — purpose-built LLM tracing (input, output, model, tokens, latency, retries, errors) so the demo is one dashboard, not a custom UI.

## Beyond Core

- PDF export alongside Markdown (`jspdf`, client-side)
- Drag-and-drop `.txt` upload
- Inline editing with debounced auto-save (PATCH per field)
- Distinct error states (`transcript_too_short`, `transcript_too_long`, `llm_invalid_output`)
- Retry once on malformed LLM JSON before bubbling 502

## What I Cut and Why

- **Streaming output** — doesn't pair cleanly with JSON mode; would double transport complexity for minimal UX gain.
- **Transcript chunking** — model context handles realistic meeting lengths; chunking is map-reduce complexity for ~0% of expected inputs.
- **Search on history** — needs FTS5; not on the rubric.
- **Re-processing existing meetings** — tempts schema changes; out of scope.
- **Auth, rate limiting, request caching** — internal tool, single user.

## What I'd Improve

- A better model (e.g. `gpt-4o-mini`) with billing enabled — `gpt-oss-120b:free` occasionally needs the retry; a stronger model would near-eliminate it.
- Owner normalization (map "Sarah" / "Sarah M." / "SM" to a canonical person).
- Long-transcript chunking with map-reduce summarization once we hit real-world transcripts that exceed the context.
- Drag-and-drop reordering of action items / decisions.
- An undo stack for inline edits.

## Langfuse Screenshot

See `langfuse-trace.png` (captured during the backend plan).
```
